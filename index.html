分子／蛋白質 3D 生成文獻地圖

焦點：Few-step generation × 3D representation / SE(3) × physical / geometric constraints × inference-time correction。整理至 2026-10-01。目的不是取代逐篇閱讀，而是先建立技術歷史與研究缺口地圖。

2020–2022

3D 幾何基礎

SE(3)/E(3) equivariance、GNN、3D molecular diffusion，解決分子在旋轉和平移下應保持一致物理語義的問題。

2023–2024

Protein diffusion → Flow

FrameDiff、Genie、RFdiffusion、Chroma 建立 backbone generation；FoldFlow / FrameFlow 把 protein generation 推入 SE(3) flow matching。

2025–2026

Few-step × Physics

ReQFlow、SiD-Protein、SE(3)-MeanFlow 專攻效率；Neural SHAKE、ADMM、ProteinGS 讓幾何／物理約束直接參與生成。

一、現在的研究版圖

Few-step 本身已不足以構成 novelty。 主線已經從「能不能生成蛋白質」進到「怎麼在 SE(3)、quaternion、latent space 上快速生成」，甚至 ProteinGS 已展示 2-step 並同時 enforce physical validity。

修改後的方向是：

Few-step → 中間 trajectory 何時開始出現 physical / geometric failure？ → 能否用便宜 signal 提前偵測？ → 是否只在必要時介入？

本次廣泛檢索沒有找到一篇完整同時滿足： few-step protein generation + intermediate physical violation profiling + violation-triggered selective correction + 與 fixed correction / extra NFE 的成本比較。這代表「目前搜尋未發現」，不是證明世界上一定沒有。

二、技術時間線：怎麼走到今天

2020｜SE(3)-Transformers

NeurIPS 2020：3D attention 對 rotation + translation 保持 equivariance。建立後續 molecular geometry 的語言。

2021｜E(n)-Equivariant GNN

ICML 2021：用較輕量 message passing 保持旋轉、平移、反射與 permutation equivariance。

2022｜3D molecular diffusion 成形

GeoDiff, ICLR 2022；Equivariant Diffusion for Molecule Generation in 3D, ICML 2022；Complete Local Frames, ICML 2022。核心從 graph property prediction 轉到「直接生成 3D coordinates / conformations」。

2022–2023｜Protein backbone diffusion 爆發

SMCDiff、ProteinSGM、Genie, ICML 2023、FrameDiff, ICML 2023、RFdiffusion、Chroma。Representation 分出 Cα、all-backbone atoms、SE(3) residue frames、graph geometry 等路線。

2023｜Flow Matching 成為另一條主幹

Flow Matching for Generative Modeling, ICLR 2023：以 vector-field regression 訓練 CNF；可使用 diffusion path，也可用更直接的 OT path。

2023–2024｜Protein → SE(3) Flow

FoldFlow, ICLR 2024：SE(3)-Stochastic Flow Matching；FrameFlow：相較 FrameDiff 報告約 5× fewer sampling timesteps，且 designability 更高；Riemannian Flow Matching, ICLR 2024建立 general manifold FM 基礎。

2024｜Representation 擴到 sequence / all-atom

FoldFlow-2 加入 sequence-conditioned SE(3) flow；Protpardelle走 all-atom diffusion；AlphaFold 3用 diffusion module 直接操作 raw atom coordinates（主要是 structure prediction，不等同 de novo backbone generation）。

2025｜少步問題從 solver 轉向 long-transition learning

Shortcut Models, ICLR 2025學 desired step size；MeanFlow學 average velocity；High-Order Matching加入 acceleration / jerk 等 higher-order supervision。

2025｜Protein few-step 形成明確子領域

ReQFlow, ICML 2025：quaternion flow + rectification；SiD-Protein：直接套 vision distillation 會導致不可接受的低 designability，需要 multistep + inference-time noise modulation，並報告 >20× speedup。

2025｜Physics / geometry 直接進入 generation loop

Neural SHAKE：每個 diffusion step 投影回 constraint manifold；On the Guidance of Flow Matching, ICML 2025建立 general flow guidance 框架；Physical Feedback, ICML 2025用 physical model energy feedback 校準 conformation ensemble；Energy-Based Flow Matching, ICML 2025把 energy-based view 帶進 3D molecular FM。

2025–2026｜Hard constraints 與 few-step 交會

Constrained Diffusion + ADMM：predict-clean → proximal feasibility → renoise；Let Physics Guide Your Protein Flows：physics-motivated unfolding/noising，保 bond、避免 collision。

2026｜2-step + physical validity 真正出現

ProteinGS, ICLR 2026：differentiable Gauss-Seidel projection，training + inference enforce physical validity；2-step model 報告可達 200-step baselines 相近 structural accuracy，約 10× wall-clock speedup。SE(3)-MeanFlow：MeanFlow on Lie groups，few-step regime 優勢更明顯。

2026｜All-atom / latent 持續擴張

La-Proteina, ICLR 2026：backbone 顯式 + per-residue latent 表示 sequence / atomistic details，做 joint all-atom structure-sequence flow matching。

四、少步問題的歷史演變

1. 早期：sampling cost

問題被理解成 reverse steps / NFE 太多。主要工具：solver、flow matching、OT path、distillation。

2. 中期：trajectory approximation

Shortcut / High-Order / MeanFlow 開始問：一個 long transition 到底要預測什麼，不再只是把 step size 放大。

3. Protein-specific：geometry / representation

SE(3)、quaternion、local frame 讓「少步」變成 manifold 上的問題。SiD-Protein 也顯示 vision distillation 不能直接搬。

4. 現在：few-step × validity

Hard projection、proximal correction、differentiable physical layers 已進場。最新競爭點正在從「快」轉為「快而不破壞幾何／物理」。

實驗設計關鍵：不要直接把 raw violation magnitude 當 failure。中間 state 原本就可能很 noisy，因此最好考慮 time/noise normalization，例如 R(x_t,t) 相對同一 t 的正常分布，而不是全程一個固定 threshold。

七、主流方向與未來推測

預測 1：fixed budget → adaptive budget

根據 geometry / uncertainty / violation 決定是否多做 NFE，而不是所有 sample 固定 steps。

預測 2：endpoint → trajectory metrics

極少步普及後，failure onset、recoverability、constraint residual 會比只看 final scRMSD 更重要。

預測 3：soft + hard hybrid

soft steering 保持 manifold，必要時才 hard projection，可能比全程硬約束更平衡。

預測 4：backbone → all-atom / sequence co-generation

failure 指標會擴到 sidechain、chemistry、sequence-structure coupling。

預測 5：Physics 變成 runtime controller

不是只有 L + λL_phys，而是決定 step size、rollback、extra NFE、projection strength。

預測 6：geometry-aware long transitions

MeanFlow / quaternion / Lie-group 方法暗示：少步主戰場會是「長距 transition 的 manifold-aware modeling」。

八、研究位置

不要 claim：
1)「Few-step protein generation 是新的」；2)「physics + few-step 是新的」；3)「physically valid 就等於 correct protein structure」。ProteinGS 已直接挑戰前兩個說法，第三個在概念上也不成立。
較有機會成立的問題：

Can cheap physical / geometric signals characterize and predict failure onset along few-step protein generation trajectories, and can they trigger selective interventions that are more cost-effective and less disruptive than fixed projection or simply adding NFEs?

最小可驗證三階段

Stage做什麼成功條件若失敗
1 Characterize同一 generator 改 steps/NFE，保存每個 intermediate state；量 bond/angle/Cα/clash/frame。少步 failure 有穩定 pattern，且不是單純 noise magnitude。沒有 trajectory signature 就不該急著做 controller。
2 Predict看早期/中期 residual 能否預測 final scRMSD / designability。normalized physical signal 有 predictive value。physics metric 可能只能診斷，不能當 trigger。
3 Intervene比 no correction / extra NFE / per-step projection / final relaxation / selective correction。相近 compute 下，selective correction 改善 quality + validity。若 simply extra NFE 更便宜有效，feedback 沒必要。

九、排序

  1. SE(3)-MeanFlow (2026)：主讀，理解 few-step protein 前沿。
  2. FrameDiff → FoldFlow / FrameFlow：只抓 representation 與 diffusion→flow 脈絡。
  3. ProteinGS (2026)：一定要讀摘要、方法圖、ablation，因為它直接影響你的 novelty。
  4. Neural SHAKE + ADMM constrained diffusion：建立 correction baseline。
  5. SiD-Protein：抓 few-step failure / designability，不必深陷 distillation 細節。
  6. High-Order Matching / MeanFlow：補 long-transition reasoning。
